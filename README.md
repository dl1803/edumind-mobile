# EduMind Mobile App (Android Native)

Nền tảng học trực tuyến tích hợp AI Trợ giảng cho học viên.

## Tech Stack
- **Ngôn ngữ:** Kotlin 1.9+
- **UI Framework:** Jetpack Compose (BOM 2024.02.00) + Material 3
- **Dependency Injection:** Dagger Hilt 2.50
- **Asynchronous:** Coroutines & StateFlow
- **Networking:** Retrofit 2.9.0 + OkHttp 4.12.0
- **Local Storage:** Room Database 2.6.1 + EncryptedSharedPreferences / DataStore
- **Media Player:** AndroidX Media3 (ExoPlayer + HLS) 1.2.1
- **Image Loading:** Coil 2.5.0

## 🛠 Yêu cầu hệ thống
- Android Studio Iguana / Jellyfish / Koala trở lên
- JDK 17 hoặc JDK 21 (mặc định đi kèm Android Studio JBR)
- Android SDK Platform 34 (Android 14)
- Min SDK: 26 (Android 8.0) | Target SDK: 34
